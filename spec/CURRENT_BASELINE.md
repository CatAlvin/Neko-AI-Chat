# V1.25.0 · 当前有效需求基线

版本号: V1.25.0  
目标: 统一当前版本的行为、默认值、兼容边界与交付判断。  
## 适用范围

本文件用于解决跨版本规则冲突。版本文档中的实现计划和验收条件不自动构成已完成证据；运行环境状态应由当次自检、消息诊断及真实收发记录确认。

## 当前产品边界

| 项目 | 当前约定 | 不应据此推断 |
| --- | --- | --- |
| NapCat | 保存多套账号配置，同一平台选择一个活动账号 | 两个 QQ 已能同时实时接入 |
| QQ 官方机器人 | 独立签名验证、收件箱和验收入口 | NapCat 通过等于官方 200 条验收通过 |

| 记忆 | 白名单且记忆开关允许；安全内容直接生效，可编辑、删除 | 任意聊天原文都永久成为记忆 |
| 本地知识 | 文本归档、词项匹配并截取相关内容 | 已部署向量数据库或语义检索集群 |
| 日历 | 北京时间日期、星期及待办到期时间 | 已同步 Outlook、农历或节假日数据库 |
| Windows 启停 | PowerShell 手动启动、停止、重启 | 登录自启、系统服务或崩溃自动拉起仍有效 |

## 消息与出站

接收、归档、生成、排队、平台受理分开记录。SHADOW 的 AI 草稿使用 SHADOWED，不能呈现成对方已收到。LIVE 仍受运行模式、账号、白名单、AI 开关、时段、限流、接管和急停控制；管理员身份不代表可以跳过所有出站限制。

发布环境与运行模式为两条状态轴：SIMULATION 用模拟链路；SHADOW 无真实发送；LIVE 才具备真实出站条件。普通自动回复只有 AUTO 允许；READ_ONLY 记录展示入站，不生成、不更新记忆与摘要。SILENT、STOPPED 不自动回复。管理员控制命令有独立的授权和模式恢复路径，不能把普通回复策略直接当成命令执行规则。

直接在 QQ 客户端发送的人类消息可能触发人工接管；后台“人工发送”走明确的操作入口，不因此触发十分钟接管等待。两者均须保留作者 HUMAN，避免当成 AI 自己的入站再次回复。

## 模型与信息来源

1. 配置优先级决定基础顺序，路由可按媒体、长文、分析、本地意图重排。
2. 管理员委托话题、截图总结优先 Kimi K3。当前 Kimi 使用 Moonshot 直连，不沿用 DashScope Kimi 示例作为默认实现。
3. “强模型优先”是维护的产品排序，不是自动基准测试结论；具体回复以 Message 保存的 provider/model 为准。
4. 本地优先路由保留云端候选，媒体能力路由可先于本地意图。需要严格不上传时，应禁用云端 Provider、媒体云上传及联网工具；不能只停用 DeepSeek。
5. 识别结果、引用材料、网页结果和知识片段均作为来源材料，而非有权修改白名单或执行管理动作的指令。
6. 默认简体中文，不附固定签名，不机械重复 Emoji。长文不完整时继续生成；确实超出平台长度时发送 PDF/TXT，不用截断正文冒充文档摘要。

## 默认值与容量

以下为代码默认值或上限，运行时已保存的配置可以不同。

| 配置 | 默认或边界 |
| --- | --- |
| 时间语义 | Asia/Shanghai；持久化时间统一比较后转换展示 |
| 常规回复时段 | 10:00–23:30；LIVE 时间门禁可开关、可配置 |
| 联系人限速 | 每分钟 5 条；连续发送上限 3 条 |
| 每日发送额度 | 默认 500，硬上限 1000 |
| 人工接管 | 默认 10 分钟 |
| 普通联系人会话 | 20 轮提示，40 轮进入冷却；管理员有专门例外 |
| 普通模型超时 | 25 秒；具体 Provider 可配置不同值 |
| NapCat 文本门槛 | 默认 1200 字符，配置范围 500–4000 |
| 长文续写 | 合计最多 4 段模型生成，检查终止原因 |
| 云媒体 | 最多 8 个；单件和总量硬上限均为 100 MiB，单件还受更小的运行时上限限制 |
| 聊天截图批次 | 最多 40 张，汇总证据最多 30000 字符 |
| 联系人长期记忆 | 最多 100 条，每条不超过 500 字符 |
| 消息导出 | 最近 30 天，Markdown，含三类作者及附件，5000 条；可设至 50000 |
| 后台任务展示 | 最多 50 条；数据库不强删未完成或待补偿任务 |
| 知识注入 | 默认取 3 个匹配片段，总计不超过 3600 字符 |

## 替代关系

- V1.22.0 的 `-` 替代旧命令参数分隔符 `|`；正文可以继续包含连字符，解析只拆第一个参数分隔点。联系人名称本身含连字符时优先使用 QQ 号。
- V1.22.0 的安全记忆直接生效替代“每条记忆都等管理员审批”；保留后台管理能力。
- V1.24.0 的手动生命周期替代 V1.18.0 的 Windows 常驻监督；不恢复计划任务、托盘守护或开机自启。
- V1.25.0 的 NapCat 兼容组合是一次升级基线，不保证之后的 QQ 自动更新继续兼容。
