## 跨图接口

- 连接器输出统一事件，交给消息流水线；ACK 不是发送回执。
- 媒体、引用、记忆、工具输出带来源的上下文，再由模型路由选择候选。
- 所有真实出站需要对应授权和当前门禁检查；普通自动回复、命令、续火各有专用规则。
- 状态最终以数据库与平台回执为依据，后台只读取并呈现证据。
- 运行图中的正常路径不代表当前机器已完成该路径验收；验收入口见 [追踪表](../TRACEABILITY.md)。
