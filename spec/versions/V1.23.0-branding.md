# V1.23.0 · Neko 图标与应用识别

版本号: V1.23.0  
目标: 为后台标签页及桌面入口增加统一的 Neko 图标，提高辨识度。  
## 资产要求

统一图形在小尺寸下仍可辨认，适配深浅背景；提供 SVG、ICO、32 像素 favicon、Apple Touch 和应用图标尺寸。源资产与生成脚本保留在项目内，页面不依赖第三方图片地址。

## 接入边界

网页通过布局元数据引用图标，浏览器标签、收藏和应用入口使用同一识别。图标更新不改变路由、登录、消息发送和服务运行方式。

本阶段桌面托盘可使用同源图标；V1.24.0 取消托盘程序后，网页图标和品牌资产继续保留，不因移除常驻程序而删除。

## 开发与验收

先确定主图形，再派生各尺寸并检查透明边缘与小尺寸可读性，最后更新布局引用。验证图标资源返回、正确 MIME、浏览器缓存更新和生产构建。

## 回退

可恢复上一版图标文件和布局引用；不需要数据库迁移或重置用户设置。生成资产不能包含本机凭据、聊天内容或截图中的隐私信息。

实现入口：`assets/`、`scripts/generate-brand-icons.py`、`frontend/app/layout.tsx`、`frontend/public/`。验收采用资源检查和实际标签页预览，不为静态图标建立业务发送测试。
