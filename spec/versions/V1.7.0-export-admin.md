# V1.7.0 · 聊天导出与管理员身份

版本号: V1.7.0  
目标: 按联系人和时间段导出聊天及附件，并允许管理员通过明确命令控制 Neko。  
## 导出要求

支持多选 1–100 位联系人、起止时间、输出目录、PDF/TXT/Markdown，以及分别包含对方、AI、本人消息。默认最近 30 天、三类作者全选、Markdown、包含附件、最多 5000 条；允许上限 50000 条。目录未指定时使用本机导出目录。

保留时间顺序、发送状态、作者、实际模型与附件关联。附件只复制已记录且实际存在的文件；缺失文件列入说明。SHADOW 内容标注未发送。日期筛选使用北京时间，导出目录不可写应在界面说明。

## 管理员入口

联系人关系增加“管理员”。公开安装由本机后台显式设置管理员，权限仍由当前账号下的联系人记录及白名单决定，不能仅凭昵称取得权限。

只允许 NapCat 管理员私聊顶层文本触发 `/neko`。群聊、普通联系人、文件内容、引用文字和模型输出均不能自行执行管理命令。无命令前缀的管理员消息仍按正常对话处理。

首批命令包括帮助、状态、账号、模型、风险、模式、急停和降级 SHADOW。急停生效后不发送确认，聊天不能升级到 LIVE。

## 实施与验收

先实现导出查询和文件生成，再接后台选择与下载；管理员身份、解析、执行与回执独立分层。验证空结果、反向时间、多个联系人、作者筛选、中文 PDF、附件缺失，以及普通用户伪造命令被拒绝。

导出与消息发送不同，导出不触发聊天。生成文件失败应清楚报告，不改源消息。管理员设置变更需审计，后续权限扩展见 V1.9.0。

实现入口：`backend/app/services/chat_export.py`、`backend/app/services/admin_commands.py`、`backend/app/schemas.py`。验证入口：`test_chat_export.py`、`test_admin_commands.py`。
