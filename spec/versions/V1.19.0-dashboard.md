# V1.19.0 · 后台导航与服务连接体验

版本号: V1.19.0  
目标: 修复侧栏溢出、分组层级不清和后台长时间卡在本机检查页的问题。  
## 导航要求

侧栏按实际任务分组，分组标题与可点击页面项使用明显不同的字重、缩进和展开标记。当前页面高亮不能与展开组混淆。长菜单独立滚动，紧急停止始终容易找到，窄屏提供可关闭导航。

分组展开状态与当前页面保持合理关联，不能导航成功后页面藏在关闭分组中。表情管理、媒体库、会话和任务板继续遵守有界列表规则。

## 启动与恢复

前端启动过程区分本机检查中、服务连接失败、首次设置、未登录和已登录。请求必须有超时及明确错误出口，失败后提供重新连接，不能无限显示加载动画。

健康请求、身份请求、页面数据分别处理。后端可用但某张卡片失败不阻塞整个后台；登录过期给出重新登录路径。WebSocket 中断可恢复刷新，但不能触发消息补发。

## 验收

在 3000 端口可访问但 8000 不可达、慢响应、无效登录态、接口报错时，页面都应结束等待并给出可理解的操作。恢复后重新连接成功，不依赖清空所有本机数据。

测试短屏、长菜单、折叠展开、键盘操作、会话历史与新消息并发；组件错误不能隐藏急停入口。

## 实施与回退

先排查启动请求依赖与异常分支，再调整导航结构和局部加载。保持已有哈希页面入口可访问。后端控制功能变化按 V1.24.0 同步更新文案。

实现入口：`frontend/app/page.tsx`、`frontend/app/globals.css`、`backend/app/api/auth.py`；验证入口：前端类型检查、构建、启动失败与恢复交互验证。
