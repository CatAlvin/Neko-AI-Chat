# V1.24.0 · 移除常驻监督并恢复手动启停

版本号: V1.24.0  
目标: 清除旧 Windows 自启、托盘和崩溃拉起，恢复 PowerShell 手动启动、停止和重启，同步后台说明。  
## 操作契约

```powershell
.\scripts\start.ps1
.\scripts\stop.ps1
.\scripts\restart.ps1
```

启动脚本执行后结束，不设置监督循环；停止后保持停止，下次开机由用户手动启动。QQ、NapCat、Ollama 和 MySQL 仍由各自方式管理。

## 清理与数据边界

核对旧计划任务实际指向本项目后导出备份，再注销。旧监督与托盘进程按可执行文件及确切脚本路径识别，不仅依赖残留 PID。清理监督状态和命令文件，保留聊天库、媒体、凭据与账号配置。

移除安装、监督、托盘和网页控制助手脚本。保留一次性卸载脚本用于旧环境迁移；它不能启动服务。路径、任务或权限不匹配时报告准确失败，不把清理失败说成成功。

## 后台调整

页面改为“手动启停与自检”，提供工作目录和启动、停止、重启命令复制。复制仅产生文本，健康检查继续可用；诊断不再建议安装监督。

旧缓存页面调用 `/system/control` 时返回 409 和手动命令，不执行操作系统启动。`/system/management` 返回当前手动方式及命令。

## 停止可靠性

核实 PID 对应进程身份，再终止其进程树。Windows 仍可枚举已退出进程时，以已核验对象的退出结果判断，避免错误阻断重启；真正停止失败则保留 PID 记录。

## 验收与回退

隔离库验证启动、重启替换 PID、停止、重复停止，以及等待后端口未重新开放。计划任务、托盘和监督进程最终为 0。旧配置备份可供恢复，但不自动重新安装已取消的运行方式。

实现入口：`scripts/start.ps1`、`scripts/stop.ps1`、`scripts/restart.ps1`、`scripts/uninstall-startup.ps1`、`services/service_control.py`；验证入口：`test_service_control.py`、`test_powershell_compatibility.py`。
