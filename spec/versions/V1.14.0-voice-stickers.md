# V1.14.0 · 本地语音、贴图与主动引用

版本号: V1.14.0  
目标: 为Neko增加可控贴图、本机少年男声回复及主动引用，修复 Whisper 中等模型切换问题。  
## 贴图库

只读扫描 QQ 的 `personal_emoji`、`marketface`、`emoji-recv` 等专用缓存候选，用户选中后复制到 Neko 贴图库并保存来源、哈希和标签。导入与自动发送分开，默认不自动附图；匹配启用贴图的触发词时才附带。

管理页可预览图片和动图，损坏或缺失资产显示失败状态。发送仍复检账号、联系人和发布门禁。

## 本机 TTS

优先离线 sherpa-onnx Kokoro 中文男声，提供可爱、活泼、温柔的少年预设，以受限音高、共鸣和节奏处理调整表现。后台展示真实引擎与预设；不承诺合成声音具有某个真实年龄。

默认在对方发语音时才尝试语音回复；开启与选择预设均可控。合成失败保留文字回复。Windows 兜底只选明确中文男声，不能确认声音类型时退回文字。

## Whisper 与引用

旧配置 `median` 规范化为 `medium`；模型未安装、下载禁止、设备内存不足分别报告。自动设备模式遇到显存不足可转 CPU int8。

主动引用开关默认关闭。开启后引用当前联系人入站；明确引用失效时允许一次不带引用的回复尝试，超时或已开始发送的未知结果不得盲目重试。

## 验收与回退

覆盖缓存导入去重、预览、触发词、男声预设、TTS 失败退文字、medium 加载与 CPU 回退、引用失效和出站回报去重。所有合成资产关联原消息；关闭功能后停止新合成，保留已生成记录。

实现入口：`local_tts.py`、`stickers.py`、`media_understanding.py`；验证入口：`test_local_voice_and_sticker_cache.py`、`test_media_understanding.py`、`test_experimental_connectors.py`。
