# V1.8.0 · 文件发送与引用内容分析

版本号: V1.8.0  
目标: 能发送文件、正确理解引用的消息和附件，并让管理员向指定白名单联系人发送内容。  
## 引用解析

保存 OneBot `reply` 原消息 ID，优先在当前会话中寻找对应消息。没有找到明确引用且当前问题含“上一条、这个文件、这张图片”等提示时，可回查本会话最近附件；普通聊天不长期携带无关文件内容。

优先复用已完成的 PDF 提取、语音转写和图片描述；缺失时按识别开关补充。请求模型前同时带上当前问题、引用正文与附件证据。找不到或未识别时明确缺失项，禁止编造引用材料。

## 出站能力

普通文件调用 NapCat `upload_private_file`，图片、语音、视频使用对应消息段。每次发送保留附件路径、类型、平台结果和消息关联；部分发送失败不能简单重试整条内容。

管理员指定发送采用“预览 → 六位代码确认”，代码 10 分钟有效。目标必须唯一、当前账号归属正确并在白名单；确认时重查 LIVE、AUTO、急停、时段、限流和内容。

本地文件从 `backend/data/sendbox` 选择相对路径，拒绝绝对路径与越界。单次最多四附件。也支持引用已保存附件消息生成发送预览。本版命令示例采用 `|` 分隔，后续统一语法由 V1.22.0 替换。

## 验收

覆盖引用 PDF 后总结、引用图片比较、语音转写问答、文件正文缺失、跨会话引用、同名联系人及确认过期。查看平台回执，不能只看“预览已生成”。账号切换或撤销白名单后，旧预览不得发送。

## 回退与实现

关闭文件发送能力可保留阅读与归档；错误附件不删除原文件。实现入口：`reference_context.py`、`admin_delivery.py`、`channels/experimental.py`；验证入口：`test_reference_context.py`、`test_admin_commands.py`。
