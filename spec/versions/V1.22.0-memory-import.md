# V1.22.0 · 聊天截图导入与直接记忆

版本号: V1.22.0  
目标: 管理员分批发送另一账号的聊天截图，提炼指定联系人的记忆；统一命令分隔符并取消新增记忆审批等待。  
## 现行命令

```text
/neko 截图开始 示例联系人2
/neko 截图结束
/neko 截图取消
/neko 记住 示例联系人2-喜欢研究图像识别
/neko 找 示例联系人2-SAM 技术的实际运用
/neko 发送 示例联系人2-今晚记得取外卖
/neko 发送文件 示例联系人2-report.pdf
/neko 时段 09:00-23:30 确认
```

目标与内容以第一个 ASCII `-` 分割，正文后续连字符保留。旧 `|` 命令给出迁移提示，不默默错认联系人。目标名称含连字符时优先使用 QQ 号避免歧义。

## 批次流程

管理员私聊开始批次并锁定当前账号下的联系人；每批最多 40 张截图、提取证据最多 30000 字符。批次期间图片强制保存并本机识别，不受普通媒体开关影响；逐张收集，不逐张 AI 聊天。

结束时优先使用 Kimi K3 整理稳定事实、偏好、关系背景、持续话题和交流习惯，再经本地校验写入记忆。未取得内容的截图不能被当成已读。保存批次、附件、识别结果、实际模型和新增数量。

## 记忆边界

可靠的规则提取、管理员直接记住和批次整理结果通过敏感内容检查后直接启用，不再等待审批。后台仍允许编辑、置顶、拒绝或删除。每条最多 500 字，每联系人最多 100 条，相同类型与内容去重。

目标记忆关闭时明确拒绝新增。仅目标联系人获得记忆，不能把截图所有人物的信息写到管理员名下；不能凭模糊昵称合并跨账号联系人。

## 验收与演进

验证开始/取消/结束、重复结束、超数量、无 OCR、错误模型、敏感信息、记忆上限、旧分隔符与含连字符正文。双 NapCat 自动同步仍是独立后续方案，截图导入不代表同时实时托管。
