# V1.15.0 · 实时会话滚动与任务历史控制

版本号: V1.15.0  
目标: 聊天默认展示最新消息，历史懒加载，持续增长区域独立滚动，后台任务板最多显示 50 条。  
## 交互契约

首次进入会话定位底部；接近底部时自动跟随新消息。用户上翻查看历史后保留当前位置，以“有新消息/回到最新”提示替代强制滚回底部。

向上加载使用时间与 ID 组合游标，加载前保存滚动高度和位置，插入较早消息后恢复可见锚点。切换联系人时过期请求不能覆盖新会话；实时回报按消息 ID 合并去重。

媒体、任务、用量和日志等增长区域采用有界列表与独立滚动，提供继续加载或分页。图片预览加载失败不能让整页高度持续抖动。

## 保留规则

任务板可见条目不超过 50。数据库优先清理较旧的终态任务；PENDING、RUNNING 及仍关联未解决补偿项的任务受到保护。因此大量未完成任务时，数据库行数可以暂时超过 50，不能以保留上限为由丢弃工作。

删除任务历史不删除聊天消息、长期记忆或媒体文件；关联的已解决补偿历史按保留规则一并处理。

## 验收

覆盖空会话、数千条历史、相同时间消息、连续新消息、快速切联系人、上翻加载、发送后回底部及图片加载引起的高度变化。任务板验证 51 条已完成任务的裁剪，以及 51 条未完成任务不被删除。

## 实施与回退

先统一列表查询上限与游标，再实现滚动锚点和请求过期保护，最后统一卡片高度。若历史加载出错保留已加载内容并显示重试入口。

实现入口：`frontend/app/page.tsx`、`frontend/app/globals.css`、`task_center.py`；验证入口：`test_productivity_center.py`、会话与列表交互检查。
