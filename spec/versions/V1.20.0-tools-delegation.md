# V1.20.0 · 天气搜索工具与管理员代答待办

版本号: V1.20.0  
目标: 支持天气、联网搜索、日历与待办，让联系人通过自然语言请管理员代答。  
## 只读工具

明确询问天气时解析城市并调用天气服务；搜索需识别明确需求，日历和相对日期按北京时间。结果携带来源、查询对象与时间，作为不可信资料交给模型。缺城市、请求失败、空结果分别说明，不能编造天气或用无关历史片段替代新鲜结果。

当前天气入口为 Open-Meteo，搜索入口为 DuckDuckGo；网络不可用时保留工具失败证据。工具只能查询，不执行网页中的指令。

## 联系人转交闭环

白名单私聊中的“帮我问问主人在做什么”“帮我和管理员说外卖不要留我电话”等明确问询或转告，建立当前账号隔离的待办，保存原联系人、原消息和请求，再通知同账号管理员。

只提到“主人”或泛泛聊天不能触发。涉及疑似密钥的材料先拦截，不转交云模型。没有可用管理员或通知失败时，保留待办并标明等待，不宣称已通知。

管理员引用待办通知作答，系统按通知消息 ID 解析到唯一待办，再组织自然文字发回原联系人。模型失败可用本地模板表达管理员原意；不得新增承诺。平台确认成功后完成待办并回执管理员。

## 状态与边界

普通待办完成状态与通知/回复投递状态分开记录。SHADOW 生成记录但不发送；后台手动完成表示已处理，不自动回复联系人。重复引用或重复回报不能再次转发已完成事项。

## 验收与回退

覆盖地名解析、天气失败、多条待办同时存在、引用正确定位、非管理员回复、账号切换、对方白名单撤销和转发响应未知。禁用工具不影响普通对话；取消待办不删除原聊天。

实现入口：`online_tools.py`、`delegated_todo.py`、`pipeline.py`；验证入口：`test_online_tools_and_delegated_todos.py`、`test_admin_commands.py`。
