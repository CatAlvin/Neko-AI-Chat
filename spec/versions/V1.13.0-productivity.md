# V1.13.0 · 异步任务与智能工作台

版本号: V1.13.0  
目标: 建立任务中心、失败补偿箱、智能路由、记忆审核、本地知识库、待办和每日聊天摘要。  
## 工作台契约

后台任务显示类型、状态、进度、尝试次数、可用时间和错误。当前任务类型为每日摘要、知识刷新和失败补偿同步，不将所有消息处理都宣称已经改为持久化异步任务。

任务状态为 PENDING、RUNNING、DONE 或 FAILED；失败有限重试并退避，达到上限转失败。失败补偿项关联原始入站、任务或消息，显示能否重试及原因。

## 知识、记忆与摘要

本地知识文档可录入、启停并按内容哈希去重；检索使用本机词项匹配，把相关片段送入 Prompt。当前不依赖向量数据库，也不承诺语义检索覆盖所有同义问题。

记忆管理显示来源、类型、审核和置顶状态，支持编辑与删除。本阶段引入审核中心；后续 V1.22.0 将可靠自动记忆改为直接启用，保留修订能力。

待办支持内容、优先级、日期和完成状态。每日摘要按北京时间归纳聊天统计和记录；23:55 后可在服务运行期间安排当日摘要，不把离线时段说成已生成。

## 模型路由

在管理员配置顺序上识别多模态、本地优先、长文档、推理和普通聊天。保留路由原因及实际尝试。路由不能启用禁用模型；“本地优先”仍有云端后备，不代表严格离线。

## 实施与验收

先建任务、补偿、知识、待办、摘要实体与迁移，再接工作台；验证任务重试上限、重复摘要、知识停用、记忆拒绝，以及不可安全重试的消息不会重发。

## 回退

停止新任务调度时保留未完成工作和失败原因；不能批量重发失败消息作为恢复措施。实现入口：`task_center.py`、`knowledge.py`、`model_router.py`、`daily_digest.py`；验证入口：`test_productivity_center.py`、`test_reliability_center.py`。
