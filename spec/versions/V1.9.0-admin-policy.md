# V1.9.0 · 管理员聊天控制联系人与模型

版本号: V1.9.0  
目标: 管理员通过聊天调整白名单、记忆、回复时段和模型顺序，并查询联系人近期记录。  
## 命令行为

- 联系人查询显示当前账号内的对象及白名单、AI、记忆、重要程度、接管与时段状态；同名要求改用 QQ 号。
- 白名单、记忆开关命令先返回影响说明，显式“确认”后写入。不能通过聊天关闭管理员自己的白名单。
- `/neko 记录 联系人 [条数]` 默认 8 条、最多 20 条；未发送的 SHADOW 内容必须标明。
- 时段支持查询、设定与开关，关闭时间限制不关闭其他发送检查。
- 模型查询列出启用项与顺位；模型优先只调整已启用项，不替用户启用无效模型。
- 帮助必须提供与解析器一致的可复制示例及错误修正提示。

## 状态边界

记忆开关关闭后停止读取与新增，原记忆保留。撤销白名单、收紧时段或停用通道时取消相关待发消息；所有操作按活动账号定位，不跨账号猜测联系人。

命令执行结果与回执发送分别记录。急停及不允许发送的模式中，后台可记录成功的控制操作，但不能为发送回执绕过急停。

## 开发顺序与验收

复用现有策略更新服务，不在命令分支复制另一套权限规则。先验证解析和对象定位，再验证原子修改与队列取消，最后验证帮助和错误反馈。

覆盖无确认、错误联系人、同名、模型未启用、跨午夜时段、查询 SHADOW 和命令重复回报。关记忆后下一次 Prompt 不得带入该联系人的长期记忆。

## 后续变更

本版时段命令曾使用两个空格分隔的时间参数；现行用法以 V1.22.0 的 `09:00-23:30` 为准。实施入口：`admin_commands.py`、`runtime.py`；验收入口：`test_admin_commands.py`、`test_control_visibility.py`。
