# V1.3.0 · 可配置 LIVE 时段与北京时间

版本号: V1.3.0  
目标: 后台可调整、开启或关闭 LIVE 回复时段，便于单联系人测试并统一北京时间。  
## 需求

SHADOW 测试可以不受自动发送时间限制；真实发送时段须有明确开关和起止时间。默认启用 `10:00–23:30`，支持跨午夜区间。关闭时段只取消时间限制，不改变联系人、账号、急停、内容或频率规则。

## 设计边界

- 所有业务时间使用 `Asia/Shanghai`；数据库存 UTC，展示和筛选边界转换为北京时间。
- 同一消息在生成、排队与真正发送之间可能跨时段，最终发送必须重新读配置和时间。
- 修改时段、降低发布门禁或收紧权限时取消受影响的待发队列。
- LIVE 开启保留阶段确认、真实入站、单联系人及唯一活动真实通道检查。
- 控制台的时段开关必须保存后可回读；不能只改变前端外观。

## 开发顺序

先增加 RuntimeState 时段字段与迁移，再复用统一时钟修正策略、续火、导出、摘要与页面展示。API 校验非法时间，界面解释跨午夜含义。

## 验收

检查开始时刻可发、结束时刻不可发、跨午夜两侧、时段关闭、SHADOW 不实际发送。模拟生成期间改时段，旧队列必须取消。Windows 与浏览器设为其他时区时，业务日期与回复时段仍为北京时间。

## 回退

恢复默认时间或降级 SHADOW；保留用户确认与修改审计。不能通过修改系统时钟完成测试。

实现入口：`backend/app/core/clock.py`、`backend/app/policy/engine.py`、`backend/app/services/runtime.py`。验证入口：`test_live_time_window.py`、`test_beijing_time.py`、`test_release_gates.py`。
